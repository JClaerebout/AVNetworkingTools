Standard capture limitations

{{ "Capture requires BPF access. This passive macOS tcpdump capture" if macos else "Run as Administrator. This passive Windows raw IPv4 capture" }} analyzes only traffic visible to the selected interface; it cannot see traffic the switch does not forward to that port. DSCP and ECN are packet markings and do not verify switch QoS queues. VLAN IDs, 802.1p/PCP and Layer-2 PTP (EtherType 0x88F7) are not visible. NIC offloading and capture loss can affect measurements. Fragmented IP packets contribute to traffic totals but are not reassembled for protocol analysis. PTP common-header decoding supports version 2 over UDP 319/320; version 1 is not decoded.

Streams become inactive after 15 seconds. Rates count IPv4 bytes over a five-second window, excluding Ethernet overhead. No vendor-specific QoS profile is selected. Leaving this page stops capture; a 30-second page heartbeat timeout provides a fallback. No Npcap installation is required.
